# Indonesian Electric Vehicle (EV) Charging Infrastructure Dataset ⚡🇮🇩

An automated dataset and interactive web dashboard tracking Electric Vehicle Charging Stations (SPKLU) and green mobility infrastructure distribution across major regions in Indonesia.

## 📊 Dataset Features
*   **Geographical Coverage:** Major provinces and urban hubs in Indonesia (DKI Jakarta, West Java, Central Java, East Java, Bali, Sumatera, etc.).
*   **Attributes:** Station name, operator/provider (e.g., PLN, Private), charging type (Fast Charging, Ultra Fast, Normal), latitude, longitude, and operational status.

## 🚀 App Features
*   Interactive geographic distribution map and regional breakdown.
*   Filter by charging operator and charger type.
*   Summary statistics and raw dataset explorer with download options.
